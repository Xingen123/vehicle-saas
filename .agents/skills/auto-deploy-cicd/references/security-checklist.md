# 生产环境安全上线检查清单 (Security Checklist)

在新项目部署至公网服务器前，必须逐项核对并完成以下加固项：

### 1. 敏感工程文件公网暴露隔离
- [ ] 检查并确保以下文件无法通过浏览器匿名直链下载：
  - `.sql` 文件（如 `install.sql`、数据库结构等）
  - 生产配置文件 `config.php`、`.env`、`install.lock`
  - 源码仓库元数据 `.git`、`.github`
  - 日志文件 `logs/*.log`、`storage/logs/*.log`
- [ ] 方案：配置 Nginx 统一阻断规则，强制返回 404（不要返回 403，404 更具隐蔽性）。

### 2. 上传目录（Uploads）防挂马与执行权限隔离
- [ ] 确保上传目录仅作为静态静态资源（图片、PDF、附件）提供访问；
- [ ] 在 Web 服务器中强制禁止解析 `.php`、`.phtml`、`.phar`、`.sh`、`.py` 等可执行文件，杜绝司机或用户上传恶意图片马提权。

### 3. 安装向导关闭
- [ ] 安装向导（如 `install.php`）在系统部署完成后，应在 Nginx 配置中阻断访问或彻底移除，防止被恶意触发覆盖线上数据库。

### 4. 账号与密码防护
- [ ] 必须将默认管理员账号（如 `admin`、`superadmin`）的初始弱口令（`admin123` 等）立即修改为高强度密码；
- [ ] 生产数据库密码使用 16 位以上混合随机字符串，仅限本地 `127.0.0.1` 访问，禁止开启公网 3306 端口。

### 5. 数据灾备与定期自动归档
- [ ] 配置 Linux Crontab 定时任务，每日凌晨自动 `mysqldump` 数据库并按日期压缩备份；
- [ ] 设置保留周期（推荐保留 30 天），过期自动清理，防止打满云服务器磁盘。
